# 🚀 Rashad Shaquille Taofik — Developer Portfolio

A modern, high-performance developer portfolio built with **Next.js 16**, **React 19**, and **Tailwind CSS v4**. Featuring a cyber-minimalist dark theme, live GitHub activity monitoring, responsive navigation, and interactive project showcases.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Deployment:** Vercel

---

## ✨ Features

- **Cyber-Minimalist Aesthetics:** High-contrast dark theme with ambient glow meshes and dot matrix background.
- **Dynamic GitHub Monitor:** Fetches live repository statistics and updates via Next.js Route Handlers.
- **Interactive Project Filtering:** Filter projects by domain (Frontend, Networking, Data Science).
- **Responsive Navigation:** Floating pill header with mobile hamburger drawer and keyboard accessibility (ESC to close).
- **Performance Optimized:** Fast load times with zero unnecessary layout shifts and optimized image delivery.

## 🏃 Getting Started

### Prerequisites
- **Node.js**: v18.18+ or v20+
- **npm**, **pnpm**, or **yarn**

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rasatshq/Portfolio-New.git
   cd Portfolio-New
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
